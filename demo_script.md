# Demo Video Script – 2 to 3 Minutes

## 1. Introduction
"Hello, this is my Password Strength and Security Analyzer developed using C."

## 2. Problem
"Users sometimes create passwords without enough length or character variety. This project provides a simple educational way to evaluate these characteristics."

## 3. Show GitHub
Open the repository and show:
- README.md
- src/password_strength_analyzer.c
- docs/project_report.md
- tests/test_cases.md

## 4. Compile
```bash
gcc src/password_strength_analyzer.c -o password_analyzer
```

## 5. Run
```bash
./password_analyzer
```

Enter a demonstration password such as:
`Test@12345`

## 6. Explain Output
Show:
- length
- security score
- strength category
- individual checks
- suggestions

## 7. Conclusion
"The project is a complete working prototype with source code, documentation, test cases and a reproducible demonstration."
